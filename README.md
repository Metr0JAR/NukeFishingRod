# NukeFishing 💣🎣💥

Turn your fishing rod into a **one-time-use nuke launcher**! 🎉  
Cast it and watch **50 TNT blocks rain from the sky** 🌩️💥. Rod glows to show it’s ready — but beware, it **breaks instantly** after use 💀!  

---

## 🚀 Features 🌟
- `/getnukerod` 🛠️ → Get a nearly broken fishing rod with 0 durability  
- `/nuke` 💣 → Activate the nuke effect  
- TNT spawns in a **square** 🌀 above your hook  
- Rod **always breaks**, even if cast in air  

---

## 📜 Commands
| Command         | Description                                               |
|-----------------|-----------------------------------------------------------|
| `/getnukerod`   | 🛠️ Get a nearly broken fishing rod with 0 durability        |
| `/nuke`         | 💣 Transform your fishing rod into a one-time-use nuke rod  |

---

## ⚡ Installation
1. Download the latest JAR and place it in your server’s `plugins` folder 📥  
2. Start or restart your Paper server 🔄
